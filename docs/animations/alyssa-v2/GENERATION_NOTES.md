# Generation and export notes

Visuals generated with the built-in Imagegen tool, using the previous Alyssa right-facing character as identity reference. New six-pose sequences were produced for idle, attack, defend, skill and damaged. Attack was regenerated again from a single-character reference to reduce overlap between effects.

Prompt constraints: preserve red hair and red/black/gold outfit; tall adult proportions; every pose faces right; fire only; full body, sword, hair and effects; transparent background; isolated poses; no labels. Idle uses breathing/hair sway, attack uses sword windup/slash/recovery, defend uses a fire shield, skill uses grimoire/fire cards, damaged uses a recoil and recovery.

Source sheets: 1536 × 1024. Final individual canvas: 4096 × 4096. Final 4K frames are upscaled exports, not newly generated native 4K detail. Extraction, transparent padding, resampling, atlas layout and preview rendering are packaging operations. Six key poses per action; no interpolated extra poses.
