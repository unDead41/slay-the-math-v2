## Run on Windows

Stop the old server with Ctrl+C. This preserves tracked edits in stash and stops
on any Git error. Keep the stash until its contents have been reviewed.

```powershell
& {
    Set-Location "C:\Users\ijmah\Desktop\slay-the-math-v2" -ErrorAction Stop
    git stash push -m "backup-before-education-main-2.36"
    if ($LASTEXITCODE -ne 0) { throw "Backup gagal." }
    git fetch origin
    if ($LASTEXITCODE -ne 0) { throw "Fetch gagal." }
    git switch main
    if ($LASTEXITCODE -ne 0) { throw "Gagal tukar ke main." }
    git pull --ff-only origin main
    if ($LASTEXITCODE -ne 0) { throw "Pull gagal." }
    npm.cmd start
}
```

Open **http://localhost:4173** and check **v2.36.0**. Use the same browser/address
to retain local saves, review ticks, comments and destination receipts. New Run
Challenge opens an Artifact trial; Predict is available during combat. Main Menu
contains Education Practice and Learning Report.

For the static production/password Hub use `npm.cmd run start:prod`. For project
Google configuration use `npm.cmd run start:dev` → localhost:4174 → Developer Hub
→ Education collection, then rebuild production. No new database is required.
