# Menara Kemungkinan Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Ship a complete two-stage browser game and portable source ZIP.
**Architecture:** Pure serializable engine and exact probability kernel, data-driven cards/enemies, shared DOM UI, original bundled SVG art. No runtime dependencies.
**Tech Stack:** HTML, CSS, JavaScript, Node built-in tests.
**Spec:** PRODUCT.md

## Global Constraints
- Malay UI. 60 HP, 3 energy, hand 4, Focus cap 3 and one boost per turn.
- Two complete stages, two bosses and guided mathematically correct forecasts.
- Offline portable build and private hosted deployment.

## Review Focus
- Empty or tiny draw pile must not trap boss progression.
- Equivalent fractions and rounded percentages must validate correctly.
- Dismissing or reloading an attempted forecast must not reset first-attempt eligibility.
- No card duplication or loss during shuffle, filter, upgrades and checkpoint retry.
- Broken storage or corrupted imports must preserve the working game.
