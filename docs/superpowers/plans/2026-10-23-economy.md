# Economy & Rewards Implementation Plan

> Agentic execution: inline in the isolated checkout, then one fresh whole-branch review under superpowers:requesting-code-review.

**Goal:** Audit and test a reproducible candidate economy without changing the current main/default gameplay.
**Architecture:** Additive versioned economy profile and immutable loot receipts used by engine, artifact and Mystery owners. Preserve legacy saves and pin external Combat baseline.
**Tech Stack:** dependency-free JavaScript, node:test, existing game engine/map, local browser QA.
**Spec:** docs/economy/DESIGN.md and user request.

## Global Constraints

Exact base 2800f9aeba5ed594e6ef3f991bcf4dfa498a5de7; branch balance/economy. No merge/push to main. Do not alter combat shuffle/question random nonrepeat, map topology or Combat stats. CP null/UNMEASURED. All tuning is candidate. Legacy snapshots unchanged.

## Review Focus

- Pending legacy rooms must resume with exact offers/prices/deadlines.
- Purchase of a discount artifact changes unsold prices without rerolling stock.
- Deck changes after an offer must not invalidate its snapshot or reroll it.
- Event Max HP costs, empty pools and resource boundaries must remain playable and atomic.
- Retry/checkpoint and malformed economy snapshots must preserve difficulty and reject invalid state.
