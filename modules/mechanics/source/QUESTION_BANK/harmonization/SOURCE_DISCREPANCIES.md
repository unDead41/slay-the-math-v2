# Source decisions for the harmonized bank

The attached textbooks and DSKP support the curriculum concepts. Questions and game scenarios are newly authored examples, not copied textbook exercises. PDF references count from the first page of the exact uploaded file; printed page labels are recorded separately.

## Some / sebilangan

English PDF page 67 and Malay PDF page 59, printed page 58, Example 3(b), reject a some-perfect-squares claim because it holds for all. This uses a conversational reading meaning some but not all. Formal existential logic permits all: some means at least one. To avoid ambiguity, the bank explicitly defines some as at least one wherever required. The conflicting example is not used as support for those answers. The textbook's counterexample discussion on printed page 69 and DSKP 3.1.1/3.1.6 provide the relevant quantified-statement context.

## Valid / sah and sound / munasabah

The first English sentence on PDF page 84, printed page 75, uses valid where the parallel Malay PDF page 76 uses munasabah. The surrounding discussion and DSKP PDF pages 57–58, printed pages 43–44, distinguish the form of a valid argument from the truth of its premises.

This bank uses: a valid argument cannot have true premises and a false conclusion; a sound deductive argument is valid and has true premises. A false premise can make an otherwise valid form unsound.

## Example 17(f)

English PDF page 85 and Malay PDF page 77, printed page 76, describe an invalid form as sound. The bank does not repeat that incompatible label. It follows the consistent validity/soundness distinction above. LOGIC-033 states the two definitions explicitly.

## Scope of the DSKP mapping

110 items are direct core practice, 7 are supporting practice and 3 are enrichment. This classification describes alignment, not an official Ministry endorsement or a validated level of mastery. Optional terms such as De Morgan's law, conditional probability, modus ponens and modus tollens remain available as explanations; their formal names are not treated as compulsory learning standards. The source map records which concept supports each local question.

Game words such as Fire, Guard, Upgraded, rune, guild and Energy are explained as local labels or stated data. Textbook references do not establish combat abilities, damage, rewards, drop rates or resource rules.
